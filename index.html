AbuseIPDB 기반 Apache 자동 차단

문제
악성 IP의 반복 접근을 수동으로 deny 목록에 넣고 재기동해야 했습니다.
조치
AbuseIPDB API로 블랙리스트를 받아 Apache 2.2/2.4 규칙 파일을 만들고 crontab으로 갱신했습니다.
결과
2.2·2.4가 섞인 환경에서도 같은 주기로 차단 목록을 유지할 수 있게 되었습니다.

Linux 서버 장애 감지 및 알림

문제
프로세스·포트 다운이나 리소스 이상을 사람이 로그를 보기 전까지 알기 어려웠습니다.
조치
top, ps, df, uptime과 프로세스·포트·저널 로그를 점검하는 스크립트를 만들고 Slack·SMS로 보냈습니다.
결과
야간·무인 시간대에도 이상 징후를 바로 받아 장애 인지 지연을 줄였습니다.
